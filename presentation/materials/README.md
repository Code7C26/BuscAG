# Identidad corporativa editable

SVG vectoriales con textos editables en Inkscape/Figma/Illustrator. Sin datos de contacto inventados. Flyer A4, sticker 70 mm, credenciales 54×86 mm, tarjeta 90×50 mm, propuesta de indumentaria y stand.

Los QR codifican el dominio confirmado del proyecto y el repositorio auténtico. Confirmar disponibilidad antes de imprimir. Regenerar: editar destinos en scripts/materials.mjs y ejecutar node scripts/materials.mjs. Para imprenta agregar sangrado y validar color y tamaño; son diseños editables, no una prueba de impresión aprobada. El símbolo original proviene del repositorio.
